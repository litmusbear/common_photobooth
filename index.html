배터리·용지: 연결하면 표시돼요

    

      
      
      
    

    
회색조는 프린터가 점마다 열 세기를 16단계로 조절해 디더링 없이 매끈하게 찍는 방식이에요(공식 앱의 사진 출력과 같은 방식). 회색조 사진 용지에서만 동작할 수 있어요. 출력이 안 되면 "흑백 점"으로 바꾸세요.

    

      
      
      
      
      
      
    

  


  
용지와 인쇄 영역 (mm)

    

      
      
      
      
      
      
      
    

    
용지 정보: 프린터를 연결하면 용지 칩(RFID)에서 크기를 읽어와요.

    
B1 Pro는 헤드 폭이 약 48mm(567픽셀)라 X+W는 48mm 안에 들어가야 해요. 테스트 출력을 하면 사진 영역에 테두리와 눈금이 찍히니, SNS 디자인과 겹치는지 보고 숫자를 조정하세요.

  


  
얼굴 보정 (갸름하게 · 눈 크게)

    

      
      
      
      
    

    

      
      
    

    

    
얼굴 인식: 준비 전

    
찍은 사진에서 얼굴을 찾아(여러 명도 가능) 턱선을 살짝 안쪽으로, 눈을 살짝 크게 바꿔요. "강하게"는 위 세기의 100%, "자연스럽게"는 55%로 적용돼요. 얼굴 인식 파일(facemesh 폴더)이 index.html 옆에 있어야 동작해요.

  


  
QR로 사진 파일 받기

    

      
      
    

    
손님이 QR을 찍으면 원본 · 보정본 · 감열지 결과를 (프레임 있는 것/없는 것) 휴대폰으로 바로 받아요. 사진은 이 아이패드 메모리에만 잠깐 있다가 위 시간이 지나거나 페이지를 새로 열면 사라져요. 부스와 손님 휴대폰 모두 인터넷이 돼야 해요.

    

      
      
      
      
    

    
GIF는 카운트다운 동안의 모습을 담아요. 카운트다운이 GIF 길이보다 짧으면 카운트다운 전체만 들어가요 (5초 GIF를 원하면 카운트다운도 5초로). 마지막 장면은 실제로 찍힌 사진으로 끝나요.

없음

      

        

          
          
        

        

          
          
        

        
용지 전체(폭 54mm × 길이 67mm)를 그대로 담은 이미지를 올리면, 인쇄 영역 설정(X·Y·W·H)대로 사진이 들어가요. 위치가 어긋나면 "인쇄 시작 위치"를 조절하세요.

      

    

  


  
출력 완료 화면

    

      
      
      
    

    
화면을 누르면 바로 처음 화면으로 돌아가요. 여러 장 출력하면 장당 1.5초씩 더 보여줘요.

  


  
대기 화면 배경

    

      
기본 화면

      

        

          
          
        

        

          
          
        

        
아이패드 화면 비율(가로 4:3 정도)로 만든 그림이 가장 잘 맞아요. 사진은 이 기기에만 저장돼요.

      

    

  


  
날짜 도장

    

      
      
      
      
      
    

    
출력하는 순간의 날짜가 찍혀요. 사진 안에 넣으면 어떤 배경에서도 보이도록 흰 글자에 검은 테두리를 둘러요.

  


  
보정

    

      
      
      
      
      
      
      
      
      
      
      
      
      
      
    

    

      
      
마지막으로 찍은 사진(없으면 샘플)에 지금 설정을 적용한 미리보기예요. 현장 조명에서 한 장 찍고 테스트 출력하면서 맞추세요. 화면보다 실제 출력이 어둡게 나오는 편이라, 화면에서 약간 밝아 보이는 정도가 보통 맞아요.
        

          
          
          
          

        
실시간 보기를 켜면 카메라 화면에 지금 보정값이 바로 적용돼요. 슬라이더를 움직이면서 확인하고, 마음에 들면 "이 장면 고정"이나 "테스트 출력"을 누르세요.

        

    

  


  
카메라와 진행
